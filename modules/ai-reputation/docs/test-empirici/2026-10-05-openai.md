- Modello effettivo: `gpt-5-mini-2025-08-07`.
- Citazioni: annotazioni `url_citation` con `url` + `title` nel `message.content[].annotations`. Gli URL
  portano `?utm_source=openai` (da pulire prima di aggregare per dominio).
- `web_search_call.action.query` restituisce le query che il modello ha fatto (utile: mostra *come* cerca).
- `include: ["web_search_call.action.sources"]` accettato.
- Il modello chiede chiarimenti sugli omonimi da solo ("ci sono almeno due profili con questo nome").

## Costi reali (listino 2026-10-05)
- Web search: **10 $ per 1.000 ricerche** (per singola `web_search_call`, non per risposta) + token di
  contesto a prezzo modello.
- Il prompt commerciale ha fatto **14 ricerche** e 57k token in ingresso: ~0,16 $ da solo.
  I prompt nav/rep: ~0,03-0,04 $ l'uno.
- **Conseguenza per il design**: limitare le ricerche per risposta (`max_tool_calls` della Responses
  API, da testare) e usare `search_context_size: low` per i cluster nav/rep. Senza cap, 50 prompt
  possono costare 3-8 $ a run solo su OpenAI.
