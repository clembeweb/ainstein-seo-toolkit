Il tuo SEO Pro autonomo per WordPress: pianifica, scrive, ottimizza e linka articoli SEO in autopilota.

== Description ==

Ainstein Editorial trasforma il tuo blog WordPress in una macchina SEO che lavora per te.
Niente da configurare, niente API key di terze parti: la licenza copre tutto.

* **Auto-pilot**: scrive un articolo a settimana basato su keyword di valore per il tuo sito.
* **Content Brain**: impara la tua voce, il tuo glossario, il tuo target.
* **Internal linking bidirezionale**: collega articoli nuovi a vecchi e viceversa, in automatico.
* **Sempre come bozza**: tu approvi, noi scriviamo.

== Installation ==

1. Acquista una licenza su https://ainstein.it/editorial
2. Carica e attiva il plugin via WP Admin → Plugins → Add New → Upload Plugin
3. Vai su "Ainstein Editorial" nel menu sinistro, incolla la license key e clicca "Attiva"
