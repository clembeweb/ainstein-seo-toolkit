## Design system landing (per chi costruisce su Carrd/Framer)

### Palette
- Background primary: `#FFFFFF` (white)
- Background alt: `#F8FAFC` (slate-50) — per sezioni alternate
- Text primary: `#0F172A` (slate-900)
- Text secondary: `#475569` (slate-600)
- Accent primary: `#6366F1` (indigo-500) — CTA buttons, link
- Accent gradient: `linear-gradient(135deg, #6366F1, #8B5CF6)` — hero CTA, highlights
- Success: `#10B981` (emerald-500) — checkmarks
- Border/divider: `#E2E8F0` (slate-200)

### Typography
- Hero headline: Inter 48-56px, weight 800
- Section heading: Inter 32-36px, weight 700
- Body: Inter 17-18px, weight 400, line-height 1.7
- Small/caption: Inter 14px, weight 400

### Spacing
- Section vertical padding: 80-100px desktop, 48-60px mobile
- Max content width: 720px (single column landing)
- Button padding: 16px 32px, border-radius 12px

### Components essenziali
- Hero CTA button: indigo gradient, white text, 18px font, 56px height, shadow
- Email input: 56px height, border slate-200, focus indigo
- Checkmark icons: emerald-500 (heroicons check-circle)
- Section divider: 80px vertical space + optional thin border

### Animazioni (subtle)
- Scroll-triggered fade-in delle sezioni (Carrd ha questa nativa)
- Hero CTA hover: lift -2px + glow indigo
- Numero "87 iscritti" counter animation al load (+2 random ogni 15s per realismo)
